# Request priority

Staff need to identify urgent equipment requests.

## Acceptance criteria

- The request form has a labeled Priority field with Low, Normal, and High choices.
- New requests default to Normal, including after the form resets.
- Requests save the selected priority and display it in the request list after reload.
- Existing requests without priority remain readable and display Normal.
- Existing required fields, newest-first ordering, and storage key remain unchanged.

Filtering, priority-based sorting, and other interface changes are out of scope.
